# Risovach

Браузерное расширение, которое накладывает референс-картинку («фантом») поверх холста
онлайн-редактора рисования. Фантом настраивается, фиксируется и синхронно следует за
зумом и перемещением холста — рисовать можно сквозь него.

Техническое задание и принятые решения: [`task.md`](./task.md).

## Статус

MVP (v0.1) + синхронизация с холстом (v0.3). Реализовано:

- загрузка картинки: файл, drag & drop, вставка из буфера (Ctrl+V);
- нормализация в статичный PNG (GIF → первый кадр), длинная сторона до 2048 px;
- свободный режим: перемещение, изменение размера за углы (пропорции, Shift — свободно);
- прозрачность, поворот, отражение, яркость, контраст, ч/б, контуры (Sobel);
- фиксация с прозрачным для мыши/пера/касаний слоем и индикатором режима;
- привязка к холсту тремя способами:
  - **RectTracking** — по умолчанию для сайтов, которые меняют прямоугольник холста;
  - **SiteAdapter** — точная модель вида для конкретных редакторов (таблица ниже);
  - **GestureSync** — запасной режим: колесо = зум по курсору, СКМ = панорама;
- переключение режима и точки привязки (курсор/центр/угол) в панели, кнопка
  «Перепривязать к холсту»;
- плавающая панель в Shadow DOM (перетаскивается, сворачивается);
- горячие клавиши и команды расширения;
- сохранение профиля домена и сессии в `chrome.storage.local` (с опцией «не сохранять»).

### Поддержка сайтов

| Сайт | Как читается вид | Проверка |
| --- | --- | --- |
| Sketchpad (`sketchpad.app`, `sketch.io`) | `sketch.doc.orient.zoom` + `sketch.doc.viewport` через MAIN-world мост | e2e: дрейф < 0.001 px при зуме и панораме |
| Loneti (`loneti.ru/draw`) | `%` из `.cont-zoom__current`, шаг зума привязывается к позиции колеса | e2e: дрейф 0 px |
| Draw.Chat (`draw.chat`) | `s` (масштаб) и `p` (pan) из URL hash | e2e: ошибка < 2 px, включая Ctrl+колесо |
| Остальные | RectTracking → GestureSync | — |

Ещё нет (см. `task.md`): калибровка по двум точкам, глобальная настройка клавиш,
поворот холста, тесты на большем числе редакторов.

## Сборка

```bash
npm install
npm run build
```

Готовое расширение — в `dist/`. Загрузить: `chrome://extensions` → включить режим
разработчика → «Загрузить распакованное» → выбрать `dist/`.

Требуется Chrome/Edge 111+ (MAIN-world content script для адаптера Sketchpad).

`npm run typecheck` — проверка типов.

## Как проверить вручную

1. `npm run dev` (поднимает Vite на `http://localhost:5173`).
2. Открыть `http://localhost:5173/test/fixture.html` — это тестовый «редактор» с
   зумом и панорамой.
3. Стрелка вниз/вправо панели: загрузить картинку, указать холст, нажать
   «Зафиксировать».
4. Менять зум кнопками `+`/`−` и панораму `Shift`+drag: фантом должен оставаться
   приклеенным к холсту (отклонение не более 2 px).
5. Рисовать по холсту сквозь фантом: штрихи должны проходить без потерь.

На sketchpad.app, loneti.ru/draw и draw.chat панель сама выбирает профиль сайта
(в строке «Активно: …») и не требует указывать холст вручную.

## Структура

```
src/
  background/      service worker: команды расширения
  content/         content script (IIFE)
    index.ts       оркестрация: состояние, сообщения, горячие клавиши
    overlay.ts     слой в Shadow DOM, фантом, ручки, выбор холста
    panel.ts       плавающая панель настроек
    canvasTracker.ts  RectTracking: rAF без пересчёта в простое
    viewSync.ts    ViewState {scale, offsetX, offsetY}: art ⇄ screen
    siteAdapter.ts адаптеры sketchpad / loneti / draw.chat
    gestureSync.ts запасной режим: зум колесом по курсору + панорама СКМ
    filters.ts     нормализация картинки, Sobel-контуры
    geometry.ts    относительные координаты, CSS-селекторы
  main-world/       MAIN-world мост: читает глобалы страницы (sketchpad)
  popup/           минимальный лаунчер
  shared/          типы, storage, сообщения
test/fixture.html  тестовый редактор для ручной проверки
```

## Принятые технические решения

- **Холст** — по умолчанию сам `<canvas>`; контейнер выбирается вручную («↑ родитель»).
  Привязка считается долями от экранного прямоугольника, а не от `canvas.width/height`.
- **Следование** — `ViewState {scale, offsetX, offsetY}` (`screen = offset + art · scale`).
  При фиксации экранный прямоугольник фантома переводится в координаты рисунка (`art`);
  дальше каждый кадр вид читается заново и фантом проецируется обратно. Для сайтов без
  адаптера — `RectTracking` по долям от прямоугольника холста.
- **Источник вида** — `SiteAdapter` на сайт (точная формула), иначе `RectTracking`,
  иначе `GestureSync`. Режим выбирается в панели («Синхр.»), по умолчанию `auto`.
- **MAIN-world мост** — content script в изолированном мире не видит глобалы страницы,
  поэтому `main-world.js` читает их и пересылает вид через `postMessage` (только при
  изменении, простой почти не тратит CPU).
- **Трансформация** — только `transform` (translate/rotate/scale), без перелайаута.
- **UI** — плавающая панель, popup только как лаунчер, side panel не используется.
- **Клавиши** — `chrome.commands` для фиксации/видимости + `keydown/keyup` в capture-фазе
  для остального (`+`/`−`, стрелки, удержание `` ` ``).
- **Фильтры** — CSS для GPU-операций, пиксельные (контуры) считаются один раз.

## Известные ограничения

- `getBoundingClientRect()` не учитывает поворот холста сайтом — привязка сломается.
- Ресайз повёрнутого фантома считается по неповёрнутой рамке.
- `RectTracking` не видит внутренний зум (прямоугольник холста не меняется): для таких
  сайтов нужен `SiteAdapter` или `GestureSync`.
- **Sketchpad**: значения читаются из глобалов страницы, поэтому нужен MAIN-world мост и
  Chrome/Edge ≥ 111.
- **Loneti**: зум кнопками интерфейса (мимо колеса) привязывается к центру или углу по
  выбранной настройке, а не к курсору; колесо отслеживается точно.
- **Draw.Chat**: поворот страницы (`r` в hash) не учитывается — только масштаб и pan.
- Контуры считаются на главном потоке (вынести в worker — v0.4).
- Панель появляется и в iframe, если там есть `<canvas>` (иначе виджет рекламы).
